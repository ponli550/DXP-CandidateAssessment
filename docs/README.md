# DXP Candidate Assessment — Documentation Contribution

This folder contains the proposed product requirements and core user flows for the DXP Front-Line Sales Candidate Assessment MVP.

## Files
- `PRD.md` — product goals, scope, requirements, validation, risks, and acceptance criteria.
- `user-flows.md` — Mermaid flow diagrams for the candidate, hiring manager, assessment administrator, assessment harness, and benchmarking journeys.

## Review notes
These documents are a proposal for team review. Confirm open questions and assumptions with the project owner before treating them as final requirements. The diagrams describe intended journeys, not implemented functionality.

## Viewing diagrams
GitHub renders Mermaid diagrams in Markdown previews. Open `user-flows.md` on GitHub to view them.
