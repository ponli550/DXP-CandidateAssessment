# Front-Line Sales Candidate Assessment MVP

DXP project, 10 weeks from 2 November 2026. Proposal: `PROPOSAL.pdf`. Plan and open questions: `KICKOFF.md`.

## How work moves

1. Every piece of work is a GitHub issue, attached to a weekly milestone.
2. Branch from `main`: `<type>/<issue>-<short-desc>`, for example `feat/10-scoring-engine`. Types: feat, fix, docs, chore.
3. Open a pull request that says `Closes #<issue>`. Keep it to one issue.
4. Tests pass, then merge with squash. Delete the branch.
5. No direct pushes to `main` after the first commit.

## Never commit

- Real candidate or employee data, in any form, including screenshots.
- Credentials, `.env` files, or videos.
- Test data must be synthetic.
